# Rancangan Website KPI PPMI Mesir

Rancangan UI/UX dan pengerjaan website untuk **Komisi Peduli Interaksi (KPI) PPMI Mesir**:
peta halaman, contoh tampilan, alur kerja, sistem warna & komponen, serta dokumen sumber
dan struktur data.

**Dirancang & dikembangkan oleh Dar Dev.**

## Isi

| Berkas | Keterangan |
|---|---|
| `index.html` | Struktur halaman & navigasi |
| `styles.css` | Sistem warna, tipografi (Sora), tata letak responsif |
| `app.js` | Data halaman, 8 contoh tampilan, alur F01-F09, kamus tabel data |
| `rancangan-ui-ux/` | Dokumen acuan (design system, peta layar, alur wireframe, cakupan) |

## Menjalankan

Situs statis, tanpa proses build. Buka `index.html` langsung, atau jalankan server lokal:

```bash
python -m http.server 8080
```

lalu buka `http://localhost:8080`.

## Catatan

Semua isi pada rancangan ini adalah contoh untuk keperluan tinjauan, bukan data resmi.
Logo resmi, foto kegiatan, dan konten lembaga menunggu penyerahan aset dari pengurus PPMI Mesir.
